# Sadoun Al-Shater

## سعدون الشاطر — Android Guardian MVP

هذا المستودع يحتوي على مشروع Android أولي لمساعد سعدون الشاطر، مع واجهة عربية، إدخال صوتي، وضع الحماية، اختبار SOS، ونظام موافقة على الأدوات.

### البناء
- Android SDK 35
- JDK 17
- Gradle 8.9
- Android Gradle Plugin 8.7.3

يمكن بناء نسخة Debug عبر GitHub Actions أو محلياً باستخدام Gradle المثبت في البيئة.

> ملاحظة: وظائف الحماية وSOS الحالية في هذه النسخة تجريبية ولا تنفذ اتصال طوارئ حقيقياً أو مراقبة خفية.
